User added AW Dropship (http://www.aw-dropship.com/, found in their Chrome shortcuts) on 2026-10-23 as a secondary sourcing site for items not available on Amazon UK, AliExpress UK or Go Dropship UK. The domain is in config.yaml approved_domains.

Cost model (from its Delivery and FAQ pages): prices shown ex-VAT, VAT 20% added at checkout (user not VAT registered); shipping extra: UK mainland 2.79 (0-99 g), 2.99 (100 g-2 kg), 5.99 (2 kg+); GBP 1 small-order fee if the order is under GBP 3 net; no registration or buying fee; dispatch 1-2 working days (3-4 Oct-Dec) plus Royal Mail Tracked 48 (2-5 days).

**Why:** product prices show only for a logged-in trade account; the user's Chrome session is signed in, so I read prices (ex-VAT, RRP) and stock counts from it; I never log in or order.
**How to apply:** landed cost = net x 1.20 + shipping (+ 1 if under 3 net). Catalogue is giftware (candles, incense, bath, gemstones, home decor), so it rarely matches the kitchen and foot-care items. See [[total-sellers-limit-2000]] for the current gate set.
