User tip 2026-10-21 (photo of ZIK Product Research rows): a purple diamond-shaped icon next to a black "a" (Amazon logo) under a listing title marks an Amazon dropshipper listing, i.e. ZIK has matched the eBay item to an Amazon supplier product. Such rows can be used to find Amazon products to run through the Amazon workflow (CLAUDE.md section 5), eBay-first.

**How to apply:** when reading ZIK rows (get_page_text drops the badges, so use a screenshot or find/read_page for the badge), note which sellers/listings carry the Amazon badge, open the matching Amazon UK product, and apply section 5 (500+ bought/month, Prime free delivery, 3-20 sellers, Keepa stability, 4% buffer, 3% ad rate). Related: [[zik-first-then-ebay]].
