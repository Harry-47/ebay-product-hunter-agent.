AliExpress cost = listed item cost (extension SKU List "Price", highest price of the last month if it changed; never struck-through, sale, new-shopper) + shipping + 4% FX buffer (UK card from 13 Oct; PKR card was 6.3%) + 6% cost buffer test. VAT is NOT added: the UK price already includes it (user's first order showed "VAT included"). The SKU List "Calculated Price" is never used. Every search uses Choice + Free shipping. Stock 20+ (50+ seasonal). No cart actions anywhere. Daily factors file: `data/fees/D_aliexpress_cost_factors.csv`.

USER 17 Oct (price from fluctuation): SKU List (logged in) is the price source for every variation; AliTool/AliPrice charts show only the FIRST/default variation and are used to judge fluctuation. If that chart is flat and its current price = its SKU List row, the SKU List prices are actual. If it fluctuates, assume the other variations fluctuate alike: factor = recent flat level / current price on the chart; actual SKU price = SKU List price x factor. In an up-and-down graph use the price of the RECENT FLAT stretch. Cross-check with a chart whose label matches the SKU when available. Never use deal/cut-off prices.
USER 17 Oct (earlier, how to find the actual price): SuperDeals / limited offers on AliExpress are fake attention deals. Verify with the AliPrice chart (and the AliTool extension if present): the FLAT, CONTINUOUS stretch of the price graph for the selected SKU is the actual price. Use that plateau price as the cost; do not use the deal price or the cut-off price. If there is no flat continuous stretch (only two points or constant movement), the actual price is unconfirmed: do not price, flag LOW. Read SKU List exact prices + inventory for the same SKU.
